# Sai Nest Hospital & Dr. Sargam Dev Soni - Official Website

Official web presence and clinical information portal for **Dr. Sargam Dev Soni**, Obstetrician, Gynecologist, and Infertility Specialist at **Sai Nest Hospital**, Borivali West, Mumbai.

## 🌟 Features & Highlights
- **Apple-Style Card Stacking UI**: Immersive, elegant specialty and credential showcases.
- **Interactive Modals & Appointment Booking**: Instant OPD consultation scheduling with WhatsApp direct booking integration.
- **Service & Blog Popups**: Comprehensive information modals for all 8 clinical specialties and health articles.
- **FAQ Accordions & Patient Testimonials**: Real patient success stories and answers to common medical queries.
- **Enterprise SEO & LLM Ready**: Fully optimized with JSON-LD structured data (`Physician`), Open Graph tags, Twitter Cards, `robots.txt`, `sitemap.xml`, and `llms.txt` / `llms-full.txt` for AI crawlers.
- **Lightning Fast Performance**: Clean vanilla HTML5 + Tailwind CSS CDN, preloaded fonts, zero bloat, and 100/100 Lighthouse PageSpeed optimized structure.

## 🚀 Deployment to Vercel & GitHub

1. **Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Sai Nest Hospital website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/sai-nest-hospital.git
   git push -u origin main
   ```

2. **Deploy on Vercel**:
   - Import your GitHub repository into Vercel.
   - Framework Preset: **Other** (Static HTML site).
   - Click **Deploy**.
